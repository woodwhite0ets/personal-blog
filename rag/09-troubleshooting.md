# 常见问题排查

## 打开网站仍然显示登录页

正确路由是：

- `/`：首页帖子内容
- `/HomePage`：首页帖子内容
- `/login`：登录页

如果浏览器仍显示旧登录页，先使用 Ctrl+F5 强制刷新，或用无痕窗口测试。前端构建产物有 hash，旧缓存通常来自浏览器缓存或旧 Service Worker。

## 提示请求太多 / 429

可能触发了登录、注册、验证码、游客或邮件限流。公开阅读不需要调用游客接口；不要通过连续刷新反复请求验证码或游客登录。

当前常见限制：

- 登录：每 IP 每分钟约 10 次
- 注册：每 IP 每分钟约 3 次
- 验证码：每 IP 每分钟约 20 次
- 验证邮件重发：每 IP 每分钟约 2 次
- 同一邮箱重置/重发：每小时约 3 次
- 全局邮件：每 60 秒约 10 封
- 游客接口：每 IP 每分钟约 30 次

## 用户无法发帖

按顺序检查：

1. 是否从 `/login` 使用真实账号登录。
2. 邮箱是否已经验证。
3. JWT 是否过期。
4. 浏览器是否加载了旧版前端。
5. 图片上传是否成功。
6. `/api/upload` 的响应状态和 `Server/logs/err.log`。

游客、未登录用户发帖会得到 401/403，这是预期行为。旧版编辑器上传 `type=content` 当前已兼容。

## 上传图片返回 400/500

- 400 `file content does not match image type`：文件扩展名/MIME 与魔数不匹配。
- 400 `invalid upload type`：上传类型不在允许列表。
- 401：没有有效 Token。
- 403：不是文章作者或没有权限。
- 500：查看后端错误日志；服务端会清理失败文件。

## Gmail 或其他邮箱收不到验证邮件

检查垃圾邮件、“所有邮件”、邮箱过滤器和地址拼写。确认后端日志有 `Mail server ready`。如果短时间请求过多，等待邮件限流窗口恢复后再点击重发。

## 忘记密码邮件收不到

确认邮箱是注册邮箱，检查垃圾箱，并确认重置 Token 没超过 1 小时。接口不会告诉调用方邮箱是否存在，以防邮箱枚举。超过限流次数后需要等待窗口恢复。

## 评论或点赞需要登录

这是正常的权限设计。公开阅读不需要登录，但评论、回复和点赞需要真实账号。未登录点赞会跳转 `/login`；评论区会显示登录链接。

## 如何判断是否有人攻击

先确认服务器日期和时区，再使用 `analyze_live.js` 查看最近行为，使用 `analyze_date.js YYYY-MM-DD` 查看指定日期。重点关注：敏感文件探测、`.git`、`.env`、WordPress/PHP 路径、管理 API、认证失败、XSS 和 SQL 注入特征。分析默认只读，不应未经确认直接封禁 IP。
